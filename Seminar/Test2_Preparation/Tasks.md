## Задача 4: Алгебрични типове - файлова система

```haskell
data FS = File String Int          -- име, размер
        | Dir String [FS]          -- име, съдържание
```

Напишете:

```haskell
totalSize :: FS -> Int
paths :: FS -> [String]                  -- пълните пътища до всички файлове
findFile :: String -> FS -> Maybe Int    -- размерът на първия файл с това име
```

```haskell
>>> let fs = Dir "root" [File "a.txt" 100, Dir "src" [File "Main.hs" 250, File "Lib.hs" 120], Dir "empty" []]
>>> totalSize fs
470
>>> paths fs
["root/a.txt","root/src/Main.hs","root/src/Lib.hs"]
>>> findFile "Lib.hs" fs
Just 120
```

## Задача 8: Функтори и `Foldable`

data Rose a = Rose a [Rose a]

## Задача 9: Монади

1. Чрез списъчната монада (`do` и `guard`) напишете `queens :: Int -> [[Int]]`.
2. Пренапишете следния код с `do`-нотация и обратно - с `>>=`:

```haskell
pairsSum :: Int -> [(Int, Int)]
pairsSum n = [1 .. n] >>= \a -> [a .. n] >>= \b -> if a + b == n then return (a, b) else []
```

```haskell
>>> length (queens 6)
4
>>> pairsSum 6
[(1,5),(2,4),(3,3)]
```
