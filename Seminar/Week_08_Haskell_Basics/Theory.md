# Въведение в Haskell

## Въведение

Втората половина на курса е посветена на **Haskell** - чисто функционален, статично типизиран, мързелив език (1990 г., кръстен на логика Хаскел Къри).

Много от идеите вече познаваме от Scheme. Новото е:

| Scheme (Racket)                        | Haskell                                         |
| -------------------------------------- | ----------------------------------------------- |
| Динамично типизиране                   | **Статично** типизиране с извод на типовете     |
| Стриктно оценяване (+ потоци)          | **Мързеливо** оценяване навсякъде               |
| `set!` позволява промяна               | **Чистота** - няма странични ефекти (освен в `IO`) |
| Префиксна нотация `(f x y)`            | Прилагане чрез интервал `f x y`, инфиксни оператори |
| `cond`, `if`                           | **Образци** (pattern matching), гардове, `if`   |

---

## 1. GHCi - интерактивна среда

### Инсталация

Използвайте [GHCup](https://www.haskell.org/ghcup/) за инсталация на GHC (компилатор) и GHCi (интерактивна среда).

### Стартиране

```bash
ghci
```

GHCi е REPL (Read-Eval-Print Loop) - като прозореца за взаимодействия в DrRacket:

```haskell
ghci> 2 + 3
5
ghci> "Hello" ++ " World"
"Hello World"
```

### Зареждане на файл

```bash
ghci> :load MyFile.hs    -- или :l MyFile.hs
ghci> :reload             -- или :r (след промяна на файла)
ghci> :type expression    -- или :t (показва типа)
ghci> :info SomeType      -- или :i (информация за тип)
ghci> :quit               -- или :q (изход)
```

> 💡 Коментарите в Haskell започват с `--` (едноредови) или са между `{-` и `-}` (многоредови).

## 2. Основни типове

| Тип       | Описание                  | Примери             |
| --------- | ------------------------- | ------------------- |
| `Int`     | Цяло число (ограничено)   | `42`, `-7`, `0`     |
| `Integer` | Цяло число (неограничено) | `123456789012345`   |
| `Double`  | Число с плаваща запетая   | `3.14`, `-0.5`      |
| `Bool`    | Булева стойност           | `True`, `False`     |
| `Char`    | Единичен символ           | `'a'`, `'Z'`, `'5'` |
| `String`  | Низ (= `[Char]`)          | `"Hello"`           |

```haskell
ghci> :t True
True :: Bool

ghci> :t 'x'
'x' :: Char

ghci> :t "hello"
"hello" :: String

ghci> :t 42
42 :: Num a => a        -- полиморфен тип: 42 може да е всякакво число
```

> 💡 За разлика от Racket, `Int` и `Double` **не се смесват** автоматично: `(1 :: Int) + 2.5` е **типова грешка**. За преобразуване се използва `fromIntegral`.

## 3. Аритметика и оператори

```haskell
ghci> 2 + 3 * 4      -- 14   (има приоритет на операциите!)
ghci> 10 / 4         -- 2.5  (дробно деление)
ghci> 10 `div` 3     -- 3    (целочислено деление - като quotient)
ghci> 10 `mod` 3     -- 1    (остатък - като modulo)
ghci> 2 ^ 10         -- 1024 (степенуване с цял показател)
ghci> 2 ** 0.5       -- 1.4142135623730951
```

### Сравнение и логически оператори

```haskell
ghci> 3 == 3          -- True
ghci> 3 /= 4          -- True   (/= е „различно“, НЕ !=)
ghci> True && False   -- False
ghci> True || False   -- True
ghci> not True        -- False
```

### Оператори и функции

Оператор в скоби става функция; функция в обратни кавички става оператор:

```haskell
ghci> (+) 3 4          -- 7
ghci> max 3 7          -- 7
ghci> 3 `max` 7        -- 7
```

## 4. Дефиниране на функции

```haskell
-- Типова сигнатура (незадължителна, но препоръчителна)
square :: Int -> Int
square x = x * x

-- Функция с два аргумента
add :: Int -> Int -> Int
add x y = x + y
```

| Scheme                          | Haskell                            |
| ------------------------------- | ---------------------------------- |
| `(define (square x) (* x x))`   | `square x = x * x`                 |
| `(square 5)`                    | `square 5`                         |
| `(add (square 2) 3)`            | `add (square 2) 3`                 |
| `(lambda (x) (* x x))`          | `\x -> x * x`                      |

> ⚠️ Няма скоби около аргументите и запетаи между тях! `add(x, y)` е грешно - правилно е `add x y`. Скобите служат само за **групиране**: `square (1 + 2)`.

> 💡 Прилагането на функция има **най-висок** приоритет: `square 2 + 3` е `(square 2) + 3 = 7`, а не `square 5`.

## 5. Условни изрази

### `if-then-else`

```haskell
absolute :: Int -> Int
absolute x = if x >= 0 then x else -x
```

> ⚠️ `else` е **задължителен** (както в Racket). Двата клона трябва да са от **един и същ тип**.

### Гардове (guards)

Аналогът на `cond`:

```haskell
sign :: Int -> Int
sign x
  | x > 0     = 1
  | x == 0    = 0
  | otherwise = -1
```

Условията се проверяват **отгоре надолу**. `otherwise` е просто `True` - като `else` в `cond`.

---

## 6. Образци (pattern matching)

Функцията се дефинира с **няколко уравнения** - за различни „форми“ на аргумента:

```haskell
factorial :: Integer -> Integer
factorial 0 = 1
factorial n = n * factorial (n - 1)
```

Проверката върви **отгоре надолу** - първият съвпадащ образец „печели“.

| Образец      | Описание                                  | Пример             |
| ------------ | ----------------------------------------- | ------------------ |
| Литерал      | Точна стойност                            | `0`, `True`, `'a'` |
| Променлива   | Съвпада с всичко, свързва стойността      | `x`, `name`        |
| Wildcard `_` | Съвпада с всичко, **игнорира** стойността | `_`                |
| Кортеж       | Деструктурира кортеж                      | `(x, y)`           |

```haskell
isZero :: Int -> Bool
isZero 0 = True
isZero _ = False
```

> ⚠️ Ако пропуснете случай, ще получите грешка по време на изпълнение. Компилаторът предупреждава с флага `-Wall`.

### Кортежи

Кортежът е **фиксирана** поредица от стойности с потенциално **различни** типове - аналог на двойките в Scheme:

```haskell
point :: (Double, Double)
point = (3.0, 4.0)

addPairs :: (Int, Int) -> (Int, Int) -> (Int, Int)
addPairs (x1, y1) (x2, y2) = (x1 + x2, y1 + y2)
```

```haskell
ghci> fst (1, 2)      -- 1   (като car)
ghci> snd (1, 2)      -- 2   (като cdr)
```

## 7. Локални дефиниции: `let` и `where`

### `where` - след тялото

```haskell
bmi :: Double -> Double -> String
bmi weight height
  | index < 18.5 = "Поднормено"
  | index < 25.0 = "Нормално"
  | otherwise    = "Наднормено"
  where
    index = weight / height ^ 2
```

### `let ... in` - преди израза

```haskell
cylinderArea :: Double -> Double -> Double
cylinderArea r h =
  let baseArea = pi * r ^ 2
      sideArea = 2 * pi * r * h
  in  2 * baseArea + sideArea
```

> 💡 `where` и `let` съответстват на вложените `define` и `let*` в Scheme. И двете могат да дефинират и **функции**, не само стойности.

> ⚠️ Haskell е чувствителен към **отстъпите** (layout rule). Дефинициите в един `where`/`let` блок трябва да започват в една и съща колона.

## 8. Рекурсия

Както в Scheme, няма цикли - използваме рекурсия. И отново различаваме рекурсивни и итеративни процеси:

```haskell
-- Рекурсивен процес
sumTo :: Integer -> Integer
sumTo 0 = 0
sumTo n = n + sumTo (n - 1)

-- Итеративен процес (с акумулатор)
sumTo' :: Integer -> Integer
sumTo' n = helper 0 n
  where
    helper acc 0 = acc
    helper acc k = helper (acc + k) (k - 1)
```

> ⚠️ Заради мързеливостта акумулаторът в Haskell може да натрупа **отложени изчисления** (`((0 + n) + (n-1)) + ...`). Как да се борим с това ще видим в Седмица 11.

## 9. Формално: типове и currying

### Типовете като множества

Типът може да се разглежда като **множество** от стойности: `Bool = {True, False}`. Типът `A -> B` е множеството от функции от $A$ в $B$.

**Типова сигнатура** `f :: A -> B` е твърдение: „`f` е функция от $A$ в $B$“. Компилаторът го **проверява** преди изпълнението - много грешки, които в Scheme виждаме по време на изпълнение, в Haskell се хващат при компилация.

### Currying

В Haskell **всяка функция приема точно един аргумент**. Функция на „два аргумента“ всъщност е функция, която **връща функция**:

```haskell
add :: Int -> Int -> Int        -- ≡ Int -> (Int -> Int)
add x y = x + y
```

`->` е **дясно-асоциативен**, а прилагането е **ляво-асоциативно**:

$$\texttt{add 3 4} = (\texttt{add 3})\ 4$$

```haskell
ghci> let add3 = add 3    -- частично прилагане!
ghci> add3 4
7
ghci> :t add 3
add 3 :: Int -> Int
```

Математически: $A \times B \to C \;\cong\; A \to (B \to C)$. Наименованието идва от Хаскел **Къри** (Haskell Curry).

> 💡 В Scheme същото се постига ръчно: `(define (add x) (lambda (y) (+ x y)))` - както `make-adder` от Седмица 3. В Haskell е **по подразбиране**.

### Извод на типовете

Сигнатурите са незадължителни - компилаторът **извежда** типа сам (алгоритъм на Хиндли–Милнър):

```haskell
ghci> let twice f x = f (f x)
ghci> :t twice
twice :: (t -> t) -> t -> t
```

`t` е **типова променлива** - `twice` работи за **всеки** тип `t`. Това е **параметричен полиморфизъм** (Седмица 10).
