## Задача 4: Мемоизация чрез мързелив списък

Наивната `fib` е експоненциална. Мързеливите списъци дават мемоизация „безплатно“:

```haskell
memoFib :: Int -> Integer
memoFib = (map fib [0..] !!)
  where fib 0 = 0
        fib 1 = 1
        fib n = memoFib (n - 1) + memoFib (n - 2)
```

1. Обяснете защо `memoFib 90` се пресмята моментално.
2. Със същата техника напишете `memoCatalan :: Int -> Integer` за числата на Каталан $C_0 = 1$, $C_{n+1} = \sum_{i=0}^{n} C_i C_{n-i}$.

```haskell
>>> memoFib 90
2880067194370816120
>>> map memoCatalan [0..10]
[1,1,2,5,14,42,132,429,1430,4862,16796]
```

## Задача 7: Стриктност

За всяка функция определете дали е стриктна (т.е. дали $f\ \bot = \bot$):

```haskell
f1 x = x + 1
f2 x = 42
f3 x = if x > 0 then 1 else 2
f4 xs = case xs of { [] -> 0; (_:_) -> 1 }
f5 (a, b) = 1
f6 ~(a, b) = 1        -- ~ означава „мързелив образец“
```

Проверете отговорите си с `f undefined` в GHCi.
