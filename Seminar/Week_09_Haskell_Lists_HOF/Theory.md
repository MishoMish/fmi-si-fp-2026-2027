## 1. Структура на списък

Списъкът е или:

- `[]` - празен списък (като `'()`)
- `x : xs` - елемент `x`, свързан с опашка `xs` (като `(cons x xs)`)

```haskell
-- Тези три записа са еквивалентни:
[1, 2, 3]
1 : [2, 3]
1 : 2 : 3 : []
```

> 💡 `:` е дясно-асоциативен: `1 : 2 : 3 : [] = 1 : (2 : (3 : []))`.

Типът на списък от елементи от тип `a` е `[a]`:

```haskell
ghci> :t [True, False]
[True, False] :: [Bool]
ghci> :t "abc"
"abc" :: String          -- String е синоним на [Char]
ghci> [1, 'a']
-- error: No instance for (Num Char) - списъкът трябва да е хомогенен!
```

| Scheme                 | Haskell                 |
| ---------------------- | ----------------------- |
| `'()`                  | `[]`                    |
| `(cons x xs)`          | `x : xs`                |
| `(list 1 2 3)`         | `[1, 2, 3]`             |
| `(car xs)`, `(cdr xs)` | `head xs`, `tail xs` - или по-добре образци |
| `(null? xs)`           | `null xs`               |
| `(append xs ys)`       | `xs ++ ys`              |

## 2. Образци за списъци

```haskell
myLength :: [a] -> Int
myLength []     = 0
myLength (_:xs) = 1 + myLength xs

firstTwo :: [a] -> Maybe (a, a)    -- Maybe ще обясним в Седмица 10
firstTwo (x:y:_) = Just (x, y)
firstTwo _       = Nothing
```

| Образец       | Съвпада с                        |
| ------------- | -------------------------------- |
| `[]`          | Празен списък                    |
| `(x:xs)`      | Непразен списък; `x` - глава, `xs` - опашка |
| `[x]`         | Списък с точно един елемент      |
| `(x:y:rest)`  | Списък с поне два елемента       |
| `all@(x:xs)`  | **As-образец**: `all` е целият списък |

```haskell
-- As-образец: дублира първия елемент
dupFirst :: [a] -> [a]
dupFirst all@(x:_) = x : all
dupFirst []        = []
```

> ⚠️ `head []` и `tail []` хвърлят грешка по време на изпълнение. Предпочитайте образци - така компилаторът (с `-Wall`) ще ви предупреди, ако забравите случая `[]`.

## 4. Кортежи и списъци

Кортежите са **хетерогенни** и с **фиксирана** дължина; списъците - **хомогенни** и с **произволна** дължина.

```haskell
ghci> zip [1, 2, 3] "abc"
[(1,'a'),(2,'b'),(3,'c')]
ghci> unzip [(1, 'a'), (2, 'b')]
([1,2],"ab")
ghci> lookup 2 [(1, "one"), (2, "two")]     -- като assoc
Just "two"
```

> 💡 Списък от двойки `[(k, v)]` е аналогът на асоциативния списък от Седмица 6, а `lookup` - на `assoc`.

## 5. Функции от по-висок ред

### `map` и `filter`

```haskell
map :: (a -> b) -> [a] -> [b]
map _ []     = []
map f (x:xs) = f x : map f xs

filter :: (a -> Bool) -> [a] -> [a]
filter _ [] = []
filter p (x:xs)
  | p x       = x : filter p xs
  | otherwise = filter p xs
```

```haskell
ghci> map (* 2) [1, 2, 3]
[2,4,6]
ghci> filter even [1..10]
[2,4,6,8,10]
```

### `foldr` и `foldl`

```haskell
foldr :: (a -> b -> b) -> b -> [a] -> b
foldr _ z []     = z
foldr f z (x:xs) = f x (foldr f z xs)

foldl :: (b -> a -> b) -> b -> [a] -> b
foldl _ z []     = z
foldl f z (x:xs) = foldl f (f z x) xs
```

$$\texttt{foldr}\ f\ z\ [x_1, x_2, x_3] = f\ x_1\ (f\ x_2\ (f\ x_3\ z))$$
$$\texttt{foldl}\ f\ z\ [x_1, x_2, x_3] = f\ (f\ (f\ z\ x_1)\ x_2)\ x_3$$

`foldr` „замества“ всяко `:` с `f` и `[]` с `z`:

```
  :           f
 / \         / \
1   :   →   1   f
   / \         / \
  2   :       2   f
     / \         / \
    3  []       3   z
```

```haskell
ghci> foldr (-) 0 [1, 2, 3]    -- 1 - (2 - (3 - 0))
2
ghci> foldl (-) 0 [1, 2, 3]    -- ((0 - 1) - 2) - 3
-6
```

> ⚠️ **Разлика с Racket!** В Haskell функцията на `foldl` получава **първо акумулатора**: `f acc x`. В Racket е `(op x acc)`. Затова `foldl (flip (:)) [] xs` обръща списък в Haskell, а в Racket - `(foldl cons '() xs)`.

### Още функции от по-висок ред

| Функция      | Тип                                     | Пример                                   |
| ------------ | --------------------------------------- | ---------------------------------------- |
| `zipWith`    | `(a -> b -> c) -> [a] -> [b] -> [c]`    | `zipWith (+) [1,2] [10,20]` → `[11,22]`  |
| `takeWhile`  | `(a -> Bool) -> [a] -> [a]`             | `takeWhile (<3) [1..]` → `[1,2]`         |
| `dropWhile`  | `(a -> Bool) -> [a] -> [a]`             | `dropWhile (<3) [1..5]` → `[3,4,5]`      |
| `any`, `all` | `(a -> Bool) -> [a] -> Bool`            | `any even [1,3,4]` → `True`              |
| `concatMap`  | `(a -> [b]) -> [a] -> [b]`              | като `append-map`                        |
| `iterate`    | `(a -> a) -> a -> [a]`                  | `take 4 (iterate (*2) 1)` → `[1,2,4,8]`  |
| `span`       | `(a -> Bool) -> [a] -> ([a], [a])`      | `span even [2,4,5,6]` → `([2,4],[5,6])`  |

## 6. Ламбди, сечения и композиция

### Ламбда изрази

```haskell
\x -> x + 1          -- (lambda (x) (+ x 1))
\x y -> x + y        -- функция на два аргумента
\(x, y) -> x + y     -- с образец
```

### Сечения на оператори

Частично приложен инфиксен оператор:

```haskell
(+ 3)     -- \x -> x + 3
(3 -)     -- \x -> 3 - x
(> 5)     -- \x -> x > 5
(`div` 2) -- \x -> x `div` 2
```

> ⚠️ `(- 3)` е **числото** -3, не сечение! Използвайте `subtract 3`.

### Композиция `(.)` и прилагане `($)`

```haskell
(.) :: (b -> c) -> (a -> b) -> a -> c
(f . g) x = f (g x)              -- compose от Седмица 3

($) :: (a -> b) -> a -> b
f $ x = f x                      -- с най-нисък приоритет
```

```haskell
ghci> (length . filter even) [1..10]
5
ghci> sum $ map (^2) $ filter odd [1..10]
165
```

### `flip`, `curry`, `uncurry`

```haskell
flip    :: (a -> b -> c) -> b -> a -> c
curry   :: ((a, b) -> c) -> a -> b -> c
uncurry :: (a -> b -> c) -> (a, b) -> c
```

```haskell
ghci> map (uncurry (+)) [(1, 2), (3, 4)]
[3,7]
ghci> flip div 10 100
10
```

## 7. List comprehensions

Синтаксис, вдъхновен от математическия запис на множества $\{x^2 \mid x \in \{1..10\}, x \text{ нечетно}\}$:

```haskell
[x ^ 2 | x <- [1..10], odd x]          -- [1,9,25,49,81]
```

```haskell
[<израз> | <генератор>, <условие>, let <дефиниция>, ...]
```

### Няколко генератора

```haskell
ghci> [(x, y) | x <- [1..3], y <- "ab"]
[(1,'a'),(1,'b'),(2,'a'),(2,'b'),(3,'a'),(3,'b')]

-- Зависими генератори - Питагорови тройки
ghci> [(a, b, c) | c <- [1..20], b <- [1..c], a <- [1..b], a^2 + b^2 == c^2]
[(3,4,5),(6,8,10),(5,12,13),(9,12,15),(8,15,17),(12,16,20)]
```

### Еквивалентност с `map`/`filter`

```haskell
[f x | x <- xs, p x]   ≡   map f (filter p xs)
[(x, y) | x <- xs, y <- ys]   ≡   concatMap (\x -> map (\y -> (x, y)) ys) xs
```

## 8. Формално: свойства на функциите за списъци

Списъците в Haskell са **индуктивен** тип (както в Седмица 4), затова можем да доказваме свойства по **структурна индукция**.

**Твърдение.** `map f (xs ++ ys) = map f xs ++ map f ys`

- **База** `xs = []`: `map f ([] ++ ys) = map f ys = [] ++ map f ys = map f [] ++ map f ys` ✓
- **Стъпка** `xs = z:zs`:

```
map f ((z:zs) ++ ys)
= map f (z : (zs ++ ys))          -- дефиниция на ++
= f z : map f (zs ++ ys)          -- дефиниция на map
= f z : (map f zs ++ map f ys)    -- индукционно предположение
= (f z : map f zs) ++ map f ys    -- дефиниция на ++
= map f (z:zs) ++ map f ys        -- дефиниция на map  ✓
```

### Полезни закони

| Закон                                      | Име                   |
| ------------------------------------------ | --------------------- |
| `map id = id`                              | Идентитет             |
| `map (f . g) = map f . map g`              | Сливане на `map`      |
| `filter p . filter q = filter (\x -> q x && p x)` | Сливане на `filter` |
| `foldr (:) [] = id`                        | `foldr` с конструкторите |
| `map f = foldr (\x acc -> f x : acc) []`   | `map` чрез `foldr`    |
| `sum (xs ++ ys) = sum xs + sum ys`         | Хомоморфизъм          |

> 💡 Тези закони не са само теория - компилаторът ги използва за **оптимизации** (например сливане на два обхождания в едно).
