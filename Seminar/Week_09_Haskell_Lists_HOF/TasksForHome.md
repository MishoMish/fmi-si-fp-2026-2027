## Задача 1: `groupBy'` и кодиране на сериите

1. Напишете `groupBy' :: (a -> a -> Bool) -> [a] -> [[a]]`, която групира **последователни** елементи, за които предикатът е изпълнен спрямо **първия** елемент на групата.
2. Чрез нея напишете `encode :: Eq a => [a] -> [(Int, a)]` и обратната ѝ `decode`.

```haskell
>>> groupBy' (==) [1, 1, 2, 2, 2, 3, 1]
[[1,1],[2,2,2],[3],[1]]
>>> encode "aaabccaa"
[(3,'a'),(1,'b'),(2,'c'),(2,'a')]
>>> decode [(3,'a'),(1,'b')]
"aaab"
```

## Задача 7: N царици

Напишете `queens :: Int -> [[Int]]`, която връща всички начини да се поставят `n` царици на шахматна дъска $n \times n$ така, че никои две да не се атакуват. Всяко решение е списък, в който `i`-тият елемент е редът на царицата в `i`-тата колона.

```haskell
>>> length (queens 8)
92
>>> head (queens 4)
[2,4,1,3]
```

> 💡 Рекурсия по броя колони + list comprehension с условие за безопасност.

## Задача 8: Доказателство

Докажете по структурна индукция, че за всички крайни списъци:

```haskell
length (xs ++ ys) = length xs + length ys
reverse (xs ++ ys) = reverse ys ++ reverse xs
```

където `reverse [] = []` и `reverse (x:xs) = reverse xs ++ [x]`. (Може да използвате без доказателство, че `++` е асоциативна и `xs ++ [] = xs`.)
