# Седмица 12 - Задачи за домашна работа

## Задача 1: Честотен анализ

Напишете програма, която чете текст от стандартния вход и отпечатва 10-те **най-чести** думи с броя им срещания. Думите се сравняват без значение от главни/малки букви, а препинателните знаци се игнорират.

```
$ runghc Freq.hs < book.txt
the: 1520
and: 812
of: 790
...
```

> 💡 `sortBy`, `group`, `sort` от `Data.List`; `comparing` от `Data.Ord`; `toLower`, `isAlpha` от `Data.Char`. Отделете логиката в чиста функция `topWords :: Int -> String -> [(String, Int)]`.

## Задача 2: CSV филтриране

Файлът `students.csv` има формат `име,фн,оценка1,оценка2,...`:

```
Ivan,101,5,6,4
Maria,102,6,6,5
Petar,103,3,4,3
```

Напишете програма, която:

1. чете файла
2. пресмята средната оценка на всеки студент
3. записва в `honors.csv` студентите със среден успех ≥ 5.00, сортирани по успех (намаляващо)

```
$ cat honors.csv
Maria,102,5.67
Ivan,101,5.00
```

> 💡 Напишете чиста функция `splitOn :: Char -> String -> [String]`. За форматиране с два знака след запетаята - `printf` от `Text.Printf`.

## Задача 3: TODO списък с файл

Напишете конзолно приложение за списък със задачи, което пази данните във файла `todo.txt`:

```
> add Купи хляб
Добавено: 1. Купи хляб
> add Реши домашното
Добавено: 2. Реши домашното
> list
1. Купи хляб
2. Реши домашното
> done 1
Изтрито: Купи хляб
> quit
```

При стартиране програмата зарежда съществуващия файл (ако го има).

> ⚠️ Внимавайте с мързеливото четене: ако прочетете `todo.txt` с `readFile` и после запишете в него с `writeFile`, ще получите грешка. Как да я избегнете?

## Задача 4: Монте Карло за π

Генерирайте $n$ случайни точки в квадрата $[0, 1] \times [0, 1]$. Делът на точките в четвъртинката от единичния кръг е приблизително $\pi / 4$.

Напишете **чиста** функция `estimatePi :: Int -> Int -> Double` (семе, брой точки).

```haskell
>>> estimatePi 42 100000
3.1486
```

После напишете програма, която отпечатва оценки за $n = 10, 100, 1000, \ldots, 10^6$ със случайно семе.

## Задача 5: Разбъркване на списък

Напишете **чиста** функция `shuffle :: StdGen -> [a] -> [a]`, която разбърква списък (всяка пермутация трябва да е равновероятна). После напишете програма, която разбърква тесте от 52 карти и раздава по 5 карти на 4 играчи.

> 💡 Алгоритъм: изберете случаен индекс `i`, вземете елемента на позиция `i` като първи, разбъркайте рекурсивно останалите с **новия** генератор.

## Задача 6: Анализ на лог файл

Лог файлът има редове от вида:

```
2026-10-05 12:01:33 INFO  Server started
2026-10-05 12:02:10 ERROR Database connection failed
2026-10-05 12:02:11 WARN  Retrying...
```

Напишете програма, която отпечатва:

- броя записи от всяко ниво (`INFO`, `WARN`, `ERROR`)
- всички `ERROR` съобщения
- часа с най-много записи

Обработвайте невалидните редове, като ги пропускате и броите. Представете записите с тип:

```haskell
data Level = Info | Warn | Error deriving (Show, Eq, Ord)
data Entry = Entry { date :: String, time :: String, level :: Level, message :: String }

parseEntry :: String -> Maybe Entry
```
