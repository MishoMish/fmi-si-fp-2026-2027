# Седмица 12 - Задачи за в час

## Задача 1: Ехо в обратен ред

Напишете програма, която чете редове, докато не срещне празен ред, и след това ги отпечатва в **обратен** ред.

```
$ runghc Echo.hs
едно
две
три

три
две
едно
```

> 💡 Рекурсивно действие `readLines :: IO [String]`.

---

## Задача 2: Сума на числа

Напишете програма, която чете число `n`, после `n` числа (по едно на ред), и отпечатва сумата, минимума и максимума им.

```
$ printf "3\n5\n-2\n10\n" | runghc Sum.hs
сума: 13
мин: -2
макс: 10
```

> 💡 `replicateM` от `Control.Monad`.

---

## Задача 3: `grep` с `interact`

Напишете програма, която чрез `interact` отпечатва само редовете от входа, съдържащи думата `"error"` (без значение от главни/малки букви).

```
$ printf "ok\nERROR: disk\nfine\nan error occurred\n" | runghc Grep.hs
ERROR: disk
an error occurred
```

## Задача 4: Статистика за файл

Напишете програма, която чете име на файл от потребителя и отпечатва броя редове, думи, символи и **най-дългия** ред (при равенство - първия). Ако файлът не съществува, отпечатайте подходящо съобщение (използвайте `try`).

```
Име на файл: notes.txt
Редове: 3
Думи: 6
Символи: 30
Най-дълъг ред: първи ред
```

## Задача 5: Хвърляне на монета

1. Напишете **чиста** функция `heads :: Int -> Int -> Int`, която по семе и брой хвърляния връща колко пъти се е паднало „ези“ (`True`). Използвайте `randoms` и `mkStdGen`.
2. Напишете програма, която симулира 10 хвърляния на зар с `randomRIO` и ги отпечатва.

```haskell
>>> heads 42 1000
512
```

## Задача 6: Безопасно деление

Напишете програма, която чете два реда и отпечатва частното им. Използвайте `readMaybe` и `Either`, за да обработите: невалидно първо число, невалидно второ число, деление на нула.

```
$ printf "10\n4\n" | runghc Div.hs
2.5
$ printf "10\n0\n" | runghc Div.hs
Грешка: деление на нула
$ printf "abc\n4\n" | runghc Div.hs
Грешка: "abc" не е число
```
