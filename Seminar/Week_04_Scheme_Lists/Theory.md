# Двойки и списъци в Scheme

## Въведение

Досега работихме само с **числа**. За реални задачи ни трябват **съставни данни** - стойности, изградени от по-прости стойности. В Scheme единственият вграден „лепил“ механизъм е **двойката** - от нея се изграждат списъци, дървета и всякакви структури.

---

## 1. S-изрази и `quote`

**S-израз** (symbolic expression) е:

- **атом** - число, символ, низ, булева стойност, или
- **двойка/списък** от S-изрази, записан в скоби

```scheme
42                    ; атом
foo                   ; атом (символ)
(1 2 3)               ; списък
(define (f x) (* x x)) ; списък от символи и списъци!
```

> 💡 Програмите на Scheme са **S-изрази**. Кодът и данните имат една и съща форма - това свойство се нарича **хомоиконичност**.

### `quote`

Как да кажем „списъкът `(+ 1 2)`“, а не „оцени `(+ 1 2)`“? Чрез специалната форма `quote`:

```scheme
(+ 1 2)           ; → 3
(quote (+ 1 2))   ; → '(+ 1 2)
'(+ 1 2)          ; → '(+ 1 2)    кратък запис
'foo              ; → 'foo        символът foo (не стойността на foo)
''a               ; → ''a         т.е. списъкът (quote a)
```

`quote` **не оценява** аргумента си - връща го както е написан.

## 2. Двойки: `cons`, `car`, `cdr`

```scheme
(cons a b)   ; конструира двойка от a и b
(car p)      ; първият елемент на двойката
(cdr p)      ; вторият елемент на двойката
```

```scheme
> (define p (cons 1 2))
> p
'(1 . 2)          ; „точкова“ нотация на двойка
> (car p)
1
> (cdr p)
2
```

> 💡 Имената идват от IBM 704 (1958): **c**ontents of **a**ddress / **d**ecrement part of **r**egister.

### Кутийкови диаграми (box-and-pointer)

Двойката е **кутия с две клетки**, всяка от които сочи към стойност:

```
(cons 1 2)

  ┌───┬───┐
  │ ● │ ● │
  └─│─┴─│─┘
    ▼   ▼
    1   2
```

Двойките могат да се влагат - **затвореност** (closure property): резултатът от `cons` може да бъде аргумент на `cons`.

```scheme
(cons (cons 1 2) (cons 3 4))   ; → '((1 . 2) 3 . 4)
```

### Съкращения

```scheme
(cadr x)   ≡ (car (cdr x))
(cddr x)   ≡ (cdr (cdr x))
(caddr x)  ≡ (car (cdr (cdr x)))
```

Комбинация от до 4 букви `a`/`d` между `c` и `r` е вградена. Чете се **отдясно наляво**.

## 3. Списъци

**Списък** е или:

- **празният списък** `'()`, или
- **двойка**, чийто `car` е първият елемент, а `cdr` е **списък** (останалите елементи)

```scheme
(list 1 2 3) ≡ (cons 1 (cons 2 (cons 3 '())))   ; → '(1 2 3)
```

```
'(1 2 3)

  ┌───┬───┐   ┌───┬───┐   ┌───┬───┐
  │ ● │ ●─┼──►│ ● │ ●─┼──►│ ● │ / │      / е '()
  └─│─┴───┘   └─│─┴───┘   └─│─┴───┘
    ▼           ▼           ▼
    1           2           3
```

> ⚠️ Не всяка двойка е списък! `(cons 1 2)` е двойка, но не списък - нейният `cdr` не е списък. `'(1 2 . 3)` също не е списък.

### Основни функции

| Функция          | Описание                                | Пример                              |
| ---------------- | --------------------------------------- | ----------------------------------- |
| `'()`, `empty`   | Празен списък                           |                                     |
| `null?`, `empty?`| Празен ли е?                            | `(null? '())` → `#t`                |
| `pair?`          | Двойка ли е?                            | `(pair? '(1))` → `#t`               |
| `list?`          | Списък ли е?                            | `(list? '(1 . 2))` → `#f`           |
| `list`           | Създава списък от аргументите си        | `(list 1 2)` → `'(1 2)`             |
| `first`, `rest`  | Синоними на `car` / `cdr` за списъци    | `(rest '(1 2 3))` → `'(2 3)`        |
| `length`         | Дължина                                 | `(length '(a b c))` → `3`           |
| `append`         | Слепване на списъци                     | `(append '(1) '(2 3))` → `'(1 2 3)` |
| `reverse`        | Обръщане                                | `(reverse '(1 2 3))` → `'(3 2 1)`   |
| `list-ref`       | Елемент по индекс (от 0)                | `(list-ref '(a b c) 1)` → `'b`      |
| `member`         | Опашката, започваща с елемента, или `#f`| `(member 3 '(1 3 5))` → `'(3 5)`    |
| `remove`         | Премахва първото срещане                | `(remove 2 '(1 2 3 2))` → `'(1 3 2)`|
| `range`          | Списък от числа                         | `(range 1 5)` → `'(1 2 3 4)`        |

### Рекурсия по списъци

Повечето функции над списъци следват шаблона:

```scheme
(define (f lst)
  (if (null? lst)
      <база>                              ; празен списък
      (<комбинирай> (car lst)              ; главата
                    (f (cdr lst)))))       ; рекурсия по опашката
```

```scheme
(define (my-length lst)
  (if (null? lst)
      0
      (+ 1 (my-length (cdr lst)))))

(define (my-append xs ys)
  (if (null? xs)
      ys
      (cons (car xs) (my-append (cdr xs) ys))))
```

> 💡 `append` **копира** първия списък и **споделя** втория. Сложност: $\Theta(n)$, където $n$ е дължината на **първия** списък.

## 4. Равенство на списъци

```scheme
(eq? '(1 2) '(1 2))      ; → #f   два различни обекта в паметта
(equal? '(1 2) '(1 2))   ; → #t   еднаква структура
(eq? '() '())            ; → #t   празният списък е един
```

- `eq?` - **идентичност** (един и същ обект)
- `equal?` - **структурно** равенство (рекурсивно сравнение)

`member` използва `equal?`; `memq` използва `eq?`.

## 5. Функции от по-висок ред за списъци

### `map`

Прилага функция върху **всеки** елемент:

```scheme
(map f '(x₁ x₂ ... xₙ)) → '((f x₁) (f x₂) ... (f xₙ))
```

```scheme
(map (lambda (x) (* x x)) '(1 2 3 4))   ; → '(1 4 9 16)
(map + '(1 2 3) '(10 20 30))            ; → '(11 22 33)   няколко списъка!
```

```scheme
(define (my-map f lst)
  (if (null? lst)
      '()
      (cons (f (car lst)) (my-map f (cdr lst)))))
```

### `filter`

Оставя елементите, за които предикатът е истина:

```scheme
(filter even? '(1 2 3 4 5 6))   ; → '(2 4 6)
```

```scheme
(define (my-filter p? lst)
  (cond ((null? lst) '())
        ((p? (car lst)) (cons (car lst) (my-filter p? (cdr lst))))
        (else (my-filter p? (cdr lst)))))
```

### `foldr` - дясно свиване

```scheme
(foldr op nv '(x₁ x₂ ... xₙ)) = (op x₁ (op x₂ ... (op xₙ nv)))
```

```scheme
(foldr + 0 '(1 2 3 4))      ; → 10
(foldr cons '() '(1 2 3))   ; → '(1 2 3)    копие на списъка
(foldr list '() '(1 2 3))   ; → '(1 (2 (3 ())))
```

```scheme
(define (my-foldr op nv lst)
  (if (null? lst)
      nv
      (op (car lst) (my-foldr op nv (cdr lst)))))
```

### `foldl` - ляво свиване

```scheme
(foldl op nv '(x₁ x₂ ... xₙ)) = (op xₙ ... (op x₂ (op x₁ nv)))
```

```scheme
(foldl cons '() '(1 2 3))   ; → '(3 2 1)    обръщане!
(foldl list '() '(1 2 3))   ; → '(3 (2 (1 ())))
```

```scheme
(define (my-foldl op acc lst)
  (if (null? lst)
      acc
      (my-foldl op (op (car lst) acc) (cdr lst))))
```

> ⚠️ В Racket функцията на `foldl` получава **първо елемента, после акумулатора**: `(op x acc)`. В Haskell и в много други източници редът е обратен - `f acc x`. Внимавайте при четене на чужд код!

> 💡 `foldl` генерира **итеративен** процес, `foldr` - **рекурсивен**. Свързани са с `accumulate-i` и `accumulate` от Седмица 3.

### `apply`

Прилага функция към **списък** от аргументи:

```scheme
(apply + '(1 2 3 4))    ; → 10   ≡ (+ 1 2 3 4)
(apply max '(3 9 2))    ; → 9
```

### Други полезни функции

| Функция       | Описание                                  | Пример                                       |
| ------------- | ----------------------------------------- | -------------------------------------------- |
| `andmap`      | Дали предикатът е верен за всички         | `(andmap even? '(2 4))` → `#t`               |
| `ormap`       | Дали предикатът е верен за някой          | `(ormap odd? '(2 4))` → `#f`                 |
| `build-list`  | Списък по функция на индекса              | `(build-list 4 (lambda (i) (* i i)))` → `'(0 1 4 9)` |

## 6. Дълбоки списъци

Елементите на списък могат да са списъци - получаваме **дълбоки** (вложени) списъци, т.е. дървета:

```scheme
'(1 (2 3) ((4)) 5)
```

При обхождане разглеждаме три случая: празен списък, двойка (влизаме и в `car`, и в `cdr`), атом:

```scheme
(define (count-atoms t)
  (cond ((null? t) 0)
        ((pair? t) (+ (count-atoms (car t))
                      (count-atoms (cdr t))))
        (else 1)))

> (count-atoms '(1 (2 3) ((4)) 5))
5
```

> 💡 Това е **дървовидна** рекурсия - рекурсираме и по `car`, и по `cdr`.

## 7. Формално: списъците като индуктивно определено множество

Нека $A$ е множество от атоми. Множеството $L$ на **списъците** е най-малкото множество, такова че:

1. $\texttt{'()} \in L$
2. ако $x$ е произволна стойност и $l \in L$, то $(\texttt{cons}\ x\ l) \in L$

Оттук следва **принципът на структурната индукция**: за да докажем, че свойство $P$ е вярно за всички списъци, е достатъчно да докажем:

- $P(\texttt{'()})$
- ако $P(l)$, то $P((\texttt{cons}\ x\ l))$ за всяко $x$

**Пример.** $\texttt{(length (append xs ys))} = \texttt{(length xs)} + \texttt{(length ys)}$.

- **База:** `xs = '()`: `(append '() ys) = ys`, и `(length '()) + (length ys) = (length ys)`. ✓
- **Стъпка:** `xs = (cons x xs')`: `(length (append (cons x xs') ys)) = (length (cons x (append xs' ys))) = 1 + (length (append xs' ys))`, което по индукционното предположение е `1 + (length xs') + (length ys) = (length xs) + (length ys)`. ✓

Рекурсивните функции над списъци „следват“ индуктивната дефиниция - затова е лесно да разсъждаваме за тях.

## Обобщение

| Концепция                 | Описание                                              |
| ------------------------- | ----------------------------------------------------- |
| S-израз                   | Атом или списък от S-изрази; кодът е S-израз          |
| `quote` / `'`             | Връща израза, без да го оценява                       |
| `cons`, `car`, `cdr`      | Конструктор и селектори на двойки                     |
| Списък                    | `'()` или двойка, чийто `cdr` е списък                |
| `eq?` / `equal?`          | Идентичност / структурно равенство                    |
| `map`, `filter`           | Трансформация / филтриране на елементи                |
| `foldr` / `foldl`         | Дясно / ляво свиване; в Racket `op` е `(x acc)`        |
| `apply`                   | Прилагане на функция към списък от аргументи          |
| Дълбок списък             | Списък със списъци - обхожда се по `car` и `cdr`       |
| Структурна индукция       | Доказване на свойства на рекурсивни функции           |
